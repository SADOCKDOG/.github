# ¡Hola! Soy David (SADOCKDOG)

**Developer of tools for Livestock Management, agribusiness efficiency, and digital operations.**

## Sobre mí

Soy desarrollador de software con enfoque práctico y real en sectores que necesitan innovación concreta: agropecuaria, producción y gestión empresarial.

Creo soluciones para hacer más eficiente la operación diaria, desde la gestión de ganado hasta la digitalización de tareas operativas y la automatización de procesos.

Mis proyectos principales incluyen:
- **Livestock Manager** — Sistema Integral de Gestión Ganadera
- **Cork Operations Manager** — digitalización y gestión para la industria del corcho
- APIs y herramientas de soporte para la industria

Mi objetivo es construir software útil, robusto y accesible, especialmente para pequeñas y medianas organizaciones que necesitan tecnología pero no cuentan con grandes equipos técnicos.

Si te interesa apoyar este tipo de desarrollo y ayudar a que estas herramientas sigan creciendo, puedes patrocinarme en [GitHub Sponsors](https://github.com/sponsors/SADOCKDOG).
